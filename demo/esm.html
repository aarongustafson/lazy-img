lazy-img via esm.sh

README · All demos

Class-only import with manual registration

This page loads the component class from esm.sh and registers it manually. 

<script type="module">
import { LazyImgElement } from
  'https://esm.sh/@aarongustafson/lazy-img@2.1.2/lazy-img.js?bundle&target=es2022';
customElements.define('lazy-img', LazyImgElement);
</script>

<lazy-img src="./sample.svg"
  alt="Mountain trail at sunrise illustration">
</lazy-img>

If the optional image is unavailable, open an alternative image.
