lazy-img via unpkg

README · All demos

Guarded registration helper

This page loads the guarded definition helper from unpkg and registers the element when supported. 

<script type="module">
import { defineLazyImg } from
  'https://unpkg.com/@aarongustafson/lazy-img@latest/define.js?module';
defineLazyImg();
</script>

<lazy-img src="./sample.svg"
  alt="Mountain trail at sunrise illustration">
</lazy-img>

If the optional image is unavailable, open an alternative image.
